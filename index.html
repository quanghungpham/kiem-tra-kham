Tool đối chiếu danh sách khám

Chọn 2 file Excel: một file Danh sách tổng và một file Danh sách đã khám. Tool dùng CCCD làm key chính để tìm những người chưa khám.
Hướng dẫn sử dụng Tool: Bấm tải 2 mẫu excel Danh sách tổng và Danh sách đã khám sau đó điền đầy đủ thông tin bấm nút Chọn file Excel để đẩy các file lên theo thứ tự. Sau đó bấm nút Đối chiếu danh sách và bấm nút Tải Excel danh sách chưa khám.
